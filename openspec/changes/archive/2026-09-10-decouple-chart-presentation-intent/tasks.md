- [x] 1.1 增加请求级展示意图值对象，支持 `AUTO`、`BAR`、`PIE`、`LINE`、`NONE` 和白名单指标，并让无效值规范化为默认值。
- [x] 1.2 扩展 `ToolResultRecorder`，按 `traceId` 独立保存和读取业务结果、展示意图，并在成功、失败或取消时一并清理。
- [x] 1.3 增加无外部副作用的展示意图 Tool，将其注册到两个 ChatClient，并更新系统提示词以区分业务 Tool 与展示 Tool。

- [x] 2.1 调整 `ChartCompiler`，保留四类业务结果的数据映射和默认图表，同时应用合法的图表类型与指标覆盖。
- [x] 2.2 支持 `NONE` 抑制图表，并确保无效或缺失展示意图回退默认图表而不改变可信 Tool 行数据。
